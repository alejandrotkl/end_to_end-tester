Telegram-бот для уведомлений

Бот пришлёт администратору сообщение, если задача не выполнилась целиком (сбой Playwright) или если часть проверенных ссылок не прошла проверку — с кратким описанием ошибки по каждой из первых нескольких ссылок. Настройки хранятся на сервере отдельно для каждого API-ключа.

  1. Создайте бота через @BotFather и скопируйте токен.
  2. Напишите боту любое сообщение (или добавьте его в нужный чат/канал).
  3. Узнайте chat id — например, откройте https://api.telegram.org/bot<ТОКЕН>/getUpdates после сообщения боту и найдите поле chat.id.
